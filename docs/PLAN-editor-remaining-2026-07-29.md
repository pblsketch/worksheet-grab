## 2단계 — R1 (① [+⑤, 0.5단계 결과에 따라])

> **① 완료(2026-07-29, 대장 D15)** — 0.5단계 프로브 결론대로 **R1-a**(가드를 이벤트 대상 기준으로
> 넓히기)로 닫았다. 새 편집 세션 소유자를 만들지 않았고, 되읽기는 셀·조각의 기존 `input` 리스너에
> 그대로 맡겼다. 렌더 신규 4건 + 변이 실험(가드 되돌리기 → 신규 3건만 빨강, 대조군 2건 초록 유지).
> 함정 1건: `instanceof Element` 는 **크로스 realm 에서 언제나 false** 라 정규화가 전 경로에서
> 죽었다(대조군 테스트가 잡았다).
>
> **부수 발견 — D14(미수정)**: 정규화 산출을 `insertHTML` 이 **다시 오염시킨다**. `<p>` 안에
> `<br>` 이 든 조각을 넣으면 Chrome 이 문단을 쪼개며 `font-size` 를 인라인화하고 뒷부분을 `</p>`
> 밖으로 내보낸다(프로브 `probe22` 로 확정 — 셀·조각·`<p>` 밖은 무해). richtext 는 `innerHTML` 로
> 되읽으므로 **이 오염은 모델에 저장된다**. 렌더 테스트에 `todo` 로 등록해 두었다.
>
> **⑤ 판단(레지스트리 값어치 재평가) — 레지스트리는 기각, 대안 채택 권고**
> 실체: `captureCaret`/`restoreCaret`(`selection.js:263-302`)이 `state.editingId` 기반이라 셀·조각
> 편집 중에는 **캡처가 null** 이고, 리플로우가 DOM 을 갈아끼우면 캐럿·편집 상태가 통째로 날아간다
> (그리고 `editingCell`/`editingEl` 은 죽은 노드를 가리킨 채 남는다).
> 레지스트리(`session.el`)로는 **닫히지 않는다** — 재렌더 후 `el` 은 죽은 노드라 복원에 쓸 수 없고,
> 필요한 것은 **재탐색 키**다(셀 `td[data-r][data-c]`, 조각 `.wg-part[data-part]`, 둘 다 `[data-oid]`
> 안). 따라서 새 개념을 만드는 대신 **세 모듈이 같은 인터페이스**(`captureEdit()`/`restoreEdit()`)를
> 내고 `runReflow`/`applyDocOp` 이 셋 다 부르는 쪽이 싸고 소유권 이동이 없다. 착수는 3단계 이후.
**R1-b(공유 `editingId`) 폐기** — 즉시 깨지는 곳 6군데: 열 너비 손잡이 소실(`tableEdit.js:133`) ·
크기 손잡이 소실(`canvasInline.js:315`) · **표 셀에 `/` 입력 불가**(`canvasInline.js:617-620`, 활동지에
"3/4"는 흔하다) · 조각 편집 중 서식 버블 오노출(`canvasInline.js:138`) · 그 버블에서 B → **엉뚱한 요소
되읽어 내용 훼손**(`editor.js:601`) · 본체 드래그 차단(`canvasInline.js:60`). 노린 이득은 D1 이 이미 확보.

**R1-c 편집 세션 레지스트리**: `selection.state.editSession = { kind:'object'|'cell'|'part', oid, el, sync() }`,
**`editingId` 는 파생 getter**(`session?.kind==='object' ? session.oid : null`) → 소비처 전부 바이트 불변.

**수용 기준 (C1·C2 반영 — 판별력 있는 것으로 교체)**
- **(a) 편집 대상 노드로 스코프**: 셀·조각에 서식 HTML 을 붙여넣은 직후 **그 `td`/`.wg-part` 의

  *(v2 기준 폐기 — 표 개체 프리셋은 `RenderObjectTree.js:463-464` 때문에 언제나 `<table class= style=` 를 담아 영구 빨강)*

  `applyDocOp`) 화면이 붙여넣기 직후와 같다. *수정 전엔 서식이 사라지거나 폭이 되돌아가고, 수정 후엔
  정규화된 같은 결과가 유지된다.*
  *(v2 기준 폐기 — undo 는 모델·DOM 을 쌍으로 복원해(`history.js:64-66`) 불일치가 나타나지 않는다)*
- (c) 붙여넣은 내용 우측 끝이 지면 안
- (d) 자유 텍스트·지문 본문의 기존 정규화 동작은 **바이트 동일**
- (e) *(레지스트리 채택 시)* `testSeed.js` 오라클 12곳 기대값 **하나도 안 바뀜** — 바뀌면 getter 가

- (f) *(input 을 흡수한다면)* 셀에 한 글자 입력 → `onDirty` 정확히 1회

> **착수 전에 (a)(b) 로 빨간불을 먼저 볼 것.** v1·v2 가 연속으로 실패한 지점이다.
> 실 클립보드 도구는 **선행 조건이 아니다** — `execCommand('insertHTML', false, rawHtml)` 로 결정적으로

## 3단계 — 파생 뷰 단일화 (⑦ ⑧ +미보고 1건) · ⑨(R5) 분리

|---|---|---|---|---|---|

| `onHistoryRestore` | ✓ | ✓ | ✓ | ✓ | **✗** |
| `runReflow` | **✗** | ✓ | ✓ | **✗** | ✗ |

| `commitTitle` | **✗** | **✗** | ✓ | **✗** | 자기 자신 |

- **미보고 형제(대장 추가)**: `runReflow`(`editor.js:185-225`)가 `updateAll()`/`refreshLayers()` 미호출 →
  리플로우가 개체를 페이지 간 이동시키면 좌측 레이어 목록이 낡은 구성 유지.
- **⑨(R5)**: `commitTitle`(`editor.js:821-831`)을 `applyDocOp` 경유로. 부수로 **`flushTyping()` 누락 해소**
  (제목 커밋이 직전 타이핑을 자기 undo 단계에 삼킨다 = **D10 과 같은 결함이 이 경로에 살아 있고 대장 미기재**).
- **정확성 vs 비용(원칙 3 충돌 해소)**: `ValidateWorksheet.js:71` 이 `renderedHtml` 을 **선택 인자**로 두므로
  **순수 절반은 즉시**, HTML 직렬화·DOM 측정만 디바운스하고 **그 창 동안 칩은 중립(`'재검수 중'`)**.
  조용한 초록을 만들지 않는다.
- **루프 방지**: `refreshDerived` 는 **문서를 바꾸지 않는 읽기 전용 계약**(history 단계도 쌓지 않음).

**수용**: 글자 하나 고친 뒤 저장 없이 칩·썸네일 갱신 · 제목 undo 후 앱바==모델 · 제목 커밋 500ms 안
Ctrl+Z 시 제목만 되돌아가고 직전 타이핑은 남음 · 리플로우로 페이지 넘어가면 레이어 목록 따라옴 ·
디바운스 창 동안 칩이 초록이 아님.

## 4단계 — ⑩ 빈 페이지 드롭 · ⑪ 프리셋 삭제 확인
⑩ `canvasInline.js:442` 후보 수집을 전 시트 → **포인터 아래 `.sheet`**, `:452-455` 폴백을 그 시트 안에서
(커밋 경로 `:466-467` 무변경). ⑪ 확인 절차 + 실패 표시.

## 5단계 — ④ 다쪽 float 축소 (**보류 해제**)
flow 가 빈 페이지가 사라지고 float 이 앞 페이지로 끌려온다. 무대는 `reflow.js`·`PaginateObjectTree.js`.
**착수 전 필수**: 다른 세션의 `6b7cfd6`(열 높이 제약 + 페이지네이션 배선)을 먼저 읽을 것 — 같은 함수를
방금 고쳤으므로 현재 동작이 v1 조사 시점과 다를 수 있다. **재현부터 다시 한다.**

## 별건 — ② 셀 범위 선택
v1 처방("표 안에서는 범위 선택 우선")은 **그대로 쓰면 안 된다** — `canvasInline.js:33-44` 가 이미 경고하고
`test/unit/body-drag-chokepoint.test.js` 가 강제한다(`td[data-r]` 를 막으면 표 몸통이 드래그 사각지대).
어제의 "⠿ 존치" 논거(*얇은 개체*)는 표에 적용되지 않는다. 착수 전 (a) 표만 몸통 드래그 상실 /
(b) 수식 키 요구 / (c) 표 선택 상태에서만 범위 모드 중 **택일 + 대가 명시**하는 결정 문서 필요.
**병합 자체는 오늘도 된다**(실측) → 미뤄도 교사는 작업을 완료한다.
