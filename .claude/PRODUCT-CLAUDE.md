# worksheet-grab — 한국 K-12 교사용 활동지 제작

교사의 한 문장 요청("중2 과학 옴의 법칙 활동지")을 학생용·교사용 A4 PDF 2벌로 만드는 도구입니다. API 키가 필요 없고, 여러분이 이미 구독한 AI가 콘텐츠 엔진입니다.

## 이렇게 요청하세요

"OO교과 OO단원/주제 활동지 만들어줘", "3번 문항 빼고 성찰 추가해줘", "학생용·교사용 PDF로 내보내줘" 처럼 말하면 `worksheet-grab` 스킬이 **성취기준 조회 → 기획 → 디자인 → 검수 → 내보내기**를 자동으로 수행합니다. 함께 설계하고 싶으면 "같이 설계하자", "먼저 질문해줘" 라고 하세요.

## 알아두면 좋은 점

- 활동지 상단에는 **학습 목표**("~할 수 있다")가 들어갑니다. 성취기준 원문은 기본적으로 표시하지 않고, **요청하실 때만** 교사용에 "근거 성취기준"으로 함께 표시됩니다.
- 성취기준은 2022 개정 교육과정 자료에서 **조회만** 합니다(지어내지 않습니다).
- 정답은 학생용에서 자동으로 빠지고, 정답이 새어 나갈 위험이 감지되면 학생용 출력이 막힙니다.
- 저작권 지문은 교사가 직접 넣거나, 요청하시면 AI가 창작·재구성할 수 있습니다(실존 작품 원문을 그대로 옮기지는 않습니다).
- 국어에 치우치지 않는 범교과 설계입니다(국어·과학·사회·영어).
